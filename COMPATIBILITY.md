Texture backend milestone (8b1f424): bounded GPU-resident A8R8G8B8/X8R8G8B8 and DXT1/3/5 2D storage, explicit BC device feature negotiation, full mip uploads with guest row pitch, opaque XRGB conversion, pointer/lifetime checks, and allocation accounting. Hardware GPU readback verifies payloads, including compressed 2x2 and 1x1 tail mips; worker RPC tests pass. Base compressed dimensions must be block-aligned; partial rectangles, texture COM methods, samplers and draw binding remain unimplemented. These diagnostics are not Humus rendering acceptance. Launch controls now wait for the asset manifest before enabling Start.

Texture COM milestone (02c2f6e): IDirect3DTexture9 now has the 22-slot ABI, resource/base-texture QueryInterface identity, external and device-binding reference lifetimes, CreateTexture, GetType, GetLevelCount, GetLevelDesc, full-mip LockRect/UnlockRect, and device Set/GetTexture for pixel sampler slots 0–15. Managed and default pools with a bounded dynamic usage subset are supported; shared handles, subrect locks, dirty-tracking flags, surface-level views, autogeneration and LOD methods remain explicit failures. Writable unlocks convert guest pointers to WASM linear addresses and upload to the persistent GPU texture; read-only unlocks avoid uploads. Native tests verify ABI, pitch, lock rules and binding lifetime; they do not establish original-application texture use. Clean bootstrap reproduced all 32 patched files.

Mip surface milestone (5ed93ba): GetSurfaceLevel returns a cached IDirect3DSurface9 view of the requested texture mip. GetContainer queries the actual parent texture and retains it; surface references keep textures alive without an ownership cycle. Surface and texture LockRect/UnlockRect share staging and lock state. Rectangle locks retain full-mip row pitch and return the correct byte/block offset; compressed rectangles require aligned interior edges and permit small edge mips. Writable unlock currently uploads the full mip, preserving untouched staging bytes. Native tests cover identity, stdcall, parent lifetime, shared locks and rectangle boundaries; original application calls remain gated by unavailable shader capabilities.

Sampler milestone (0712be6): device Set/GetSamplerState cache DWORD state for 16 pixel sampler slots with D3D9 defaults. The WebGPU mapper supports wrap/mirror/clamp, point/linear magnification and minification, disabled/point/linear mip filtering, and largest-mip restrictions. Sampler descriptors are cached with a 512-entry LRU bound. Eight GPU compute sampling checks verify actual colors and mip interpolation, separately from Humus scene acceptance. Border and mirror-once addressing, anisotropic filtering, nonzero LOD bias, sRGB sampling, and displacement/multielement sampling remain unsupported; application draw submission still needs to consume the cached sampler state.

Pipeline milestone (42d9423): a reusable WebGPU pipeline builder combines stored VS/PS bytecode, semantic vertex layouts, compact float input expansion, and alpha/depth/stencil/blend/cull state. Shader-pair and pipeline caches each retain at most 128 entries with a 16 MiB accounting bound; destroyed shader handles fail before cached lookup. Dynamic stencil references do not force compilation. GPU diagnostics now use these pipelines for indexed geometry, persistent BGRA texture sampling with cached samplers, alpha-tested stencil writes, additive stencil-tested lighting, and the discard/depth probe. Five pipeline variants used two linked shader translations. This is component integration; the original executable still requires draw packet serialization and submission through its D3D9 methods.

Draw bridge milestone (c119870): DrawPrimitive and DrawIndexedPrimitive now serialize shader handles, declarations, stream/index bindings, render state and shader register bits into bounded DWORD packets. The GPU worker decodes these packets, reuses linked shader/pipeline caches, packs reflected uniforms into persistent GPU buffers, and submits actual indexed or nonindexed draws. CPU-side index checks and GPU-worker stream bounds reject invalid accesses. Point/line/triangle lists are supported; textured draw binding, strips/fans, UP calls, viewport changes and broader state remain incomplete. GPU readback and real worker RPC diagnostics pass, separately from original-executable acceptance. The native host returns NOTAVAILABLE after a valid draw packet; it never fabricates GPU success.

Textured draw milestone (3a62518): draw packets now carry all 16 pixel texture handles and sampler states. SPIR-V combined-sampler splitting exports the exact texture/sampler binding pairs and image dimensions; draw submission binds the reflected 2D resources and cached samplers alongside shader uniforms. GPU tests verify textured indexed draws at both sampler slot 0 and sparse slot 7, matching RGBA [17,121,233,255], and worker RPC submission. Missing/released/locked textures and unsupported image dimensions fail explicitly. Vertex textures, cube/volume textures, viewport changes, strips/fans and UP draw calls remain incomplete.

Viewport milestone (0c6930e): Set/GetViewport preserve DWORD rectangle fields and float depth-range bits, validate pointers and render-target bounds, and reject invalid updates without changing prior state.

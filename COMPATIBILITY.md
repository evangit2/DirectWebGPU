# Original DynamicBranching compatibility checklist

Scope: the unmodified PE32 `DynamicBranching/DynamicBranching.exe`, SHA-256 `7664f1f55d71593b6af9475bef06aba811bbe8a5ec3ba690ec559064d6207bc5`. This is a tested application subset, not general Windows or D3D9 compatibility. Earlier milestone states remain in Git history.

Remaining limits: no independently verified native scene reference; lighting equivalence shares shader/rasterization code. x87 uses f64 approximations; static translation and selected API coverage do not establish general compatibility. Total browser memory, guest CRT suballocations, and exact pre-frame wire bytes are not fully measured. Startup and ordinary throughput have been refreshed after memory reduction. No working CheerpX rendering baseline exists, so no comparative speedup is claimed. Theseus licensing remains unresolved for redistribution; generated binaries/assets stay local.

`evidence/acceptance-audit.json` tracks the incomplete overall audit. `MEASURED-RESULTS.json` links current evidence; each raw report records its own revision, EXE hash, browser and run ID.
